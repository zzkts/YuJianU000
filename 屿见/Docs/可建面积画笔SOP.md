# 可建面积画笔 SOP

> 适用：屿见 · 建筑网格的可建面积（哪些格子能放建筑）。
> 工具：菜单 `屿见 → 建筑 → 可建面积画笔…`
> 版本：2026-11-20

---

## 0. 一句话流程

**打开窗口 → 创建/绑定掩码 → Scene 视图左键画、右键清 → Ctrl+S 保存场景 → Play 看格线。**

---

## 1. 前置检查

- [ ] 退出 Play Mode（画画只在编辑模式可用）。
- [ ] 打开 `Assets/Scenes/SampleScene.unity`。
- [ ] 场景里已有 `BuildingGrid`。没有就先跑 `屿见 → 建筑 → 配置建筑网格与建造相机（阶段 7）`。
- [ ] 知道当前网格的 `cellSize / cellCounts / gridCenter`（窗口会显示）。

---

## 2. 数据模型

| 概念 | 说明 |
|---|---|
| `BuildableAreaMask` | 手绘掩码资产。每格 `true = 可建`，`false = 不可建`，行优先 |
| 网格签名 | 资产里存 `gridCenter / cellSize / cellCounts`；与 `BuildingGrid` 不一致时禁止绘画并回退台地判定 |
| `useAreaMask` | `BuildingGrid` 上的开关。打开后掩码完全取代海岛台地判定 |
| 关卡污染区 | 仍由 `LevelEntrance` 运行时登记，叠在可建掩码之上；画笔不改它 |
| 建筑占用 | 运行时状态，叠在可建掩码之上；画笔不改它 |

**完全手绘模式下，`buildableInset` 不再参与判定。** 想整体收缩，用「从台地烘焙」后手动擦边，或先改 `buildableInset` 再烘焙。

---

## 3. 第一次使用

1. 菜单 `屿见 → 建筑 → 可建面积画笔…`。
2. 窗口里确认 `BuildingGrid` 已自动找到。
3. 点顶部的 **「启用 Scene 绘画（创建 / 绑定掩码）」**（高级操作里的「创建 / 绑定掩码」等价）：
   - 默认创建 `Assets/Data/Buildings/BuildableAreaMask.asset`；
   - 自动按当前海岛台地烘焙一份初始掩码；
   - 自动把掩码绑到 `BuildingGrid` 并打开 `useAreaMask`。
4. 修面积（两种入口任选）：
   - **Scene 视图**：左键画「可建」，右键清除为「不可建」；
   - **窗口「面积预览」**：俯视网格图，适合看整体轮廓和大范围修补；
   - 工具：笔刷 / 矩形 / 油漆桶；笔刷半径 0~4 格；
   - `Ctrl+Z` 撤销整笔。
5. `Ctrl+S` 保存场景（掩码资产会自动保存）。

## 4. 日常调整

| 想做的事 | 操作 |
|---|---|
| 修一小块 | 笔刷 + 左键/右键 |
| 整片开/关 | 矩形工具，拖出范围后松开 |
| 填满相连区域 | 油漆桶，点一下 |
| 全部重来 | 窗口「全部可建」/「全部不可建」 |
| 回到台地形状 | 窗口「从台地烘焙」 |
| 网格参数变了 | 窗口「按当前网格重建」 |
| 临时回到自动台地 | 关掉「BuildingGrid 使用手绘掩码」 |

### 4.1 2D 面积预览

窗口里的「面积预览」是俯视网格图，和 Scene 视图共享同一份掩码与工具：

- **绿色 = 可建，红色 = 不可建**；
- 左键画可建，右键清除；笔刷 / 矩形 / 油漆桶同样生效；
- 方向：右 = `+X`，上 = `+Z`，**下边是 `y = 0`**；
- 「缩放（像素/格）」4~16；「适应窗口」按窗口宽自动算；
- 鼠标停在格子上会显示坐标与当前状态；
- 在预览里画的每一笔会同步到 Scene 视图和 `BuildingGrid`。

适合看整体轮廓和大范围修补；需要判断建筑与地形关系时再用 Scene 视图。

### 4.2 Scene 视图颜色

- **绿色半透明 = 可建**；
- **红色半透明 = 不可建**；
- **黄色描边 = 可建区域边界**（只描绿格与非可建格 / 网格外的交界）；
- **白色描边 = 当前鼠标 / 笔刷范围**；
- Scene 视图左上角常驻提示框：操作提示 +「绿 = 可建，红 = 不可建」。

打开窗口后如果还没启用掩码，Scene 视图左上角会提示「还没启用掩码：在窗口里点『启用 Scene 绘画』」，不会出现“点了没反应”的情况。

## 5. 验收

- [ ] 窗口统计的「可建 / 总数」符合预期。
- [ ] 掩码签名与网格一致（窗口没有红色签名错误）。
- [ ] 2D 预览与 Scene 视图显示同一份掩码（在一边画，另一边同步变化）。
- [ ] Scene 视图里绿色 / 红色填充和黄色边界清楚可见；未启用时左上角有提示框。
- [ ] `Ctrl+S` 后重新打开场景，手绘内容还在。
- [ ] 进 Play：`Console` 有 `[BuildingGrid] ... 判定依据 手绘掩码`。
- [ ] 进建造模式：格线只出现在手绘可建格上；不可建格放蓝图会提示「不在可建台地上」。
- [ ] 关卡污染区在净化前仍然封锁（不会被手绘掩码绕过）。

---

## 6. 已知限制

1. **完全手绘不跟随海岛。** 改岛屿台地参数不会自动更新掩码；需要重新烘焙或手改。
2. **改网格参数会让掩码签名失效。** `cellSize / gridCenter / cellCounts` 任一变化，都要点「按当前网格重建」；旧手绘内容会丢。
3. **不要在手绘后重跑「配置建筑网格与建造相机（阶段 7）」。** 它可能改网格参数，导致签名失效。
4. **关卡污染区 / 建筑占用不是本工具的编辑对象。** 它们只在运行时叠加，画笔不显示/不修改。
5. **叠加层用 `Hidden/Internal-Colored` + 顶点色。** 如果 URP 下不可用，会自动退化为逐格 `Handles` 绘制，功能不受影响。
6. **撤销是整笔一档。** 一次拖拽 / 一次矩形 / 一次油漆桶 = 一个 Undo 步。
7. **画笔窗口需要保持打开。** 关掉窗口后 Scene 视图不再接收画笔事件；建议把它 dock 在 Scene 视图旁边。

| 场景 | 操作 |
|---|---|

| 掩码资产整个回滚 | `git checkout -- Assets/Data/Buildings/BuildableAreaMask.asset` |

---

## 8. 排错

| 现象 | 检查 |
|---|---|
| 画笔没反应 | 是否在 Play Mode；「绘画模式」是否打开；掩码是否已绑定并启用 |
| 画上去但游戏里没变 | `BuildingGrid` 的 `useAreaMask` 是否打开；Console 判定依据是否「手绘掩码」 |
| 一画就提示签名不匹配 | 网格参数变了；点「按当前网格重建」 |
| 看不到叠加层 | Scene 视图是否俯视网格平面；是否被其他物体挡住（叠加层本身是 Always 深度） |
| 掩码数组长度异常 | 点「按当前网格重建」 |

## 10. 关卡污染面积（2026-11-21）

画笔顶部多了「可建面积 / 关卡污染区」两层。关卡层可以直接手绘每个关卡的污染范围，不再只能调 4×4 矩形。

### 10.1 数据

- 每个 `LevelEntrance` 引用一张 `LevelAreaMask` 资产（`Assets/Data/Buildings/LevelArea_<关卡号>.asset`）；
- `true` = 污染格；**未净化时封锁，净化后只保留污染核心那一格**；
- 没有绑定掩码时，运行时仍回退到 `footprintCells` 矩形；
- 掩码签名（中心 / 单格 / 格数）与 `BuildingGrid` 不一致时，运行时会警告并回退矩形。

### 10.2 操作

1. 画笔顶部选「关卡污染区」；
2. 在「关卡」下拉里选要编辑的 `LevelEntrance`；
3. 点「创建 / 绑定关卡掩码」：会新建资产，并按当前 `footprintCells` 矩形烘焙一份；
4. 在 2D 预览或 Scene 视图左键画污染、右键清除；
5. `Ctrl+S` 保存场景（资产会自动保存）。

### 10.3 颜色

| 颜色 | 含义 |
|---|---|
| 橙色（高不透明度） | 当前关卡的污染格 |
| 红橙 | 污染格同时落在可建面积内（运行时关卡优先） |
| 半透明橙 | 其他关卡的污染格 |
| 极浅绿 | 当前可建面积（只作参考，透明度已压到 0.03，避免和橙混淆） |

> 在「可建面积」层里，被关卡污染覆盖的格子会直接显示为橙色，不再和绿色做混色；想同时看可建状态时切回「可建面积」层看周边绿格即可。

### 10.4 注意

- 画污染格不会修改可建面积掩码，反之亦然；两层是独立的；
- 改网格参数后，所有关卡掩码签名都会失效，需要逐个「按当前网格重建」；
- 净化后核心格永久不可建，这是沿用原有规则。

### 10.5 Scene 橙色 Gizmo（不用开画笔）

- 选中 / 不选中 `BuildingSystem` 都可以在 Scene 视图看到关卡占地：
  - 实心橙 = 手绘污染格；
  - 淡橙 = 没有掩码 / 掩码签名不匹配时的 `footprintCells` 矩形；
  - 深红 = 污染核心格（永远只占 1 格）；
  - 标签显示「关卡 N」或「关卡 N（矩形）」；如果整块在网格外，会显示「占地不在网格内」。
- 画笔窗口正在显示叠加层时，Gizmo 会跳过关卡层，避免重复。

### 10.6 垃圾自动分布

- 运行时 `LevelEnvironmentVisual` 会按关卡面积生成占位垃圾：
  - 有手绘掩码：垃圾 / 绿气 / 净化后的草花只出现在画过的格子里；
  - 没有掩码或签名不匹配：回退到 `footprintCells` 矩形；
  - 数量按格子数自动计算（每格约 2 块垃圾），视觉尺寸随单格大小缩放；
  - 污染核心永远是独立的一格，不随周边垃圾数量变化。
- 这是占位视觉（基础几何体），不是可攻击的垃圾聚合体；正式美术到位后替换。
