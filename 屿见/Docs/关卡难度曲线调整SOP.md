# 关卡难度曲线调整 SOP

> 适用：屿见 · 关卡（清洁区入口）的 **档位 / 波次 / BOSS** 曲线。
> 工具：菜单 `屿见 → 数值 → 关卡难度曲线…`
> 版本：2026-11-20

---

## 0. 一句话流程

**打开窗口 → 改 3 个数 → 看预览 → 应用 → Ctrl+S → 跑自检 → Play 验一关。**

---

## 1. 前置检查

- [ ] 退出 Play Mode。
- [ ] 打开 `Assets/Scenes/SampleScene.unity`（也支持其它已打开的关卡场景）。
- [ ] `Assets/Data/Mining/OreLevelTable.asset` 和 `Assets/Data/Mining/Tools/MiningTool_石头.asset` 已配置好。
- [ ] **不要**再跑旧的 `屿见 → 数值 → 应用原型数值 v1（关卡参数）`，它会覆盖本工具的结果。

---

## 2. 数据分工（改哪一层，心里有数）

| 数据 | 唯一来源 | 谁改 |
|---|---|---|
| 单只 HP / 奖励 | `OreTypeTable` + `OreLevelTable`（成长倍数、每档组权重） | 数值 |
| 工具攻击 / 升级费 | `MiningTool_石头.asset` | 数值 |
| 波次 / BOSS 节奏 | 本窗口顶部参数 | 关卡 |
| 关卡数量 / 先后顺序 | 场景里的 `LevelEntrance` + `levelNumber` | 关卡 |

窗口只写 `LevelEntrance` 的这几个字段：

`difficultyTier`、`unlockLevel`、`levelNumber`、`waveCount`、`bossMaxHealth`、`bossReward`、`bossHealthRegenPerSecond`、`bossCountdownSeconds`、`aggregateGroups`。

**不碰**灰化材质、战场、相机、内容根、BOSS 种类。

---

## 3. 日常调参（5 分钟）

1. 菜单打开 `屿见 → 数值 → 关卡难度曲线…`。
2. 只动这三项：
   - **每关波次**：默认 `104`（想按分钟反算就取消「固定波次」，填 `300` 秒）。
   - **BOSS 目标击杀**：默认 `20` 秒。
   - **BOSS 奖励 = 多少波小怪**：默认 `30`。
3. 看「预览」表，逐行确认：
   - 每只点击从第 1 档到第 N 档 **单调上升**；
   - 单关时长在目标 ±20%；
   - 「工具费占比」在 **20%~30%**（红色就是偏离）；
   - 没有红色错误行。
4. 点 **「应用到场景」** → 确认。
5. **Ctrl+S** 保存场景。
6. 自检：`屿见 → 数值 → 打印各层击杀次数`，确认每层的加权点击与预览一致。
7. Play 验两关：第 1 关 + 最后一关。确认波次进度、BOSS 在 30 秒内可击杀、退出重进不跳档。

---

## 4. 参数含义

| 参数 | 默认 | 公式 / 作用 | 调大会怎样 |
|---|---|---|---|
| 每关波次 | 104 | 一关要打多少只（1 聚合体 = 1 波 = 1 只） | 关更长、收入更高 |
| 点击频率 | 2 次/秒 | 只用于估算时长与 BOSS HP | 预览时长变短、BOSS 更肉 |
| 刷新间隔 | 0.2 秒 | 只用于估算时长；可点「读场景值」 | 预览时长变长 |
| BOSS 目标击杀 | 20 秒 | `BOSS HP = 该档攻击 × 秒数 × 点击频率` | BOSS 更肉 |
| BOSS 奖励波数 | 30 | `BOSS 奖励 = 该档单只奖励 × 波数` | BOSS 更值钱 |
| BOSS 回血 | 0.5% HP/秒 | `回血 = BOSS HP × 百分比` | 更难 |
| 倒计时 | 30 秒 | BOSS 战限时 | 更宽容 |
| 一关一档 | 开 | 第 N 关 → 第 N 档 | 关掉则沿用每道门原档位 |
| 对齐解锁等级 | 开 | 第 N 关解锁等级 = N | 关掉则保留原解锁条件 |
| 重排关卡号 | 开 | 按当前顺序写成 1..N | 关掉则保留原关卡号 |
| 清空专属组 | 开 | 统一走等级表的每档组 | 关掉则用每道门自己的 `aggregateGroups` |
| 自动保存 | 关 | 应用后立即存场景 | 打开后少一步 Ctrl+S，但不好整批撤销 |

> **BOSS 奖励不要按平均 HP 算。** 现在 HP ×6 / 奖励 ×5 已经脱钩；按 HP 算，第 6 关 BOSS 会发 327 万垃圾，占全关 42%。窗口用的是「30 × 单只加权奖励」。

### 4.1 名词解释：工具费占比

**工具费占比 = 升下一级工具的金币 ÷ 本关总收入（小怪 + BOSS，按 5 垃圾 = 1 金币折算）。**

- 第 1 关：`104 × 11 + 330 = 1,474` 垃圾 → `294.8` 金币；工具 1→2 要 `64` 金币；占比 `21.7%`。
- 它回答的是：**打完这一关，够不够买下一级工具，买完还剩多少。**
- 它**不是** ROI，也**不是**玩家的点击 / 时间投入；ROI 是它的倒数（约 4.6 倍）。
- 目标 20%~30%：太高（>35%）一关买不起下一级工具，下一档会打不动；太低（<15%）升级太便宜，后面的关卡失去装备检查的压力。
- 设计稿的 **28%** 是「只算 104 波小怪」的口径；窗口把 BOSS 奖励也算进分母，所以显示约 **21.7%**，两者是同一套预算。

## 5. 验收标准（红灯不提交）

- [ ] 预览表无红色错误行。
- [ ] 第 1 档点击/只 = `5.00 ± 0.10`。
- [ ] 点击/只随档位单调递增；持平/下降先查 `OreLevelTable.healthGrowthPerTier` 与工具攻击成长。
- [ ] 单关时长在目标 ±20%（固定 104 波时：第 1 档约 5.0 分钟，×6 曲线第 6 档约 11.4 分钟，这是有意的）。
- [ ] 「工具费占比」20%~30%（当前资产约 21.7%）。
- [ ] 场景里没有重复 `levelNumber`；入口数 ≤ 等级表档位数。
- [ ] Console 有 `[关卡难度曲线] 已写入：` 日志，内容与预览一致。
- [ ] Play 里进关后 Console 有「本关锁定怪物档位 N」，且同一关内血量不随玩家升级变化。

## 6. 结构性改动

### 6.1 改怪物血量 / 奖励曲线

1. 只改一个字段：`OreLevelTable.healthGrowthPerTier` 或 `rewardGrowthPerTier`。
2. 回到窗口点 **「重新读取」**。
3. 预览 → 应用 → Ctrl+S → 自检 → Play。
4. 想压时长但不想动经济：只调 `healthGrowthPerTier`（推荐 `5.5`），**不要**减波次。

### 6.2 加一关

1. 复制一个 `清洁区入口`，摆到岛上。
2. 运行 `屿见 → 关卡 → 整理关卡战场与入口（阶段 4）`。
3. 打开窗口，勾选 **「重排关卡号」**，预览会多一行。
4. 应用 → Ctrl+S。

### 6.3 加 BOSS 外观 / 换战场

不属于本 SOP，走 `LevelBattlefieldSetupWizard`（`屿见 → 关卡 → 整理关卡战场与入口`）。
